This page runs gliner-runner for you. Type a text and some labels, and it picks the label that fits. Your text
is never sent to a server: it stays in this browser tab, or goes only to the runner on your own computer.

<Playground client:only="react" />

## In this tab

**In this tab** runs the runner itself inside the page, in a background worker, with the `decide-340m` model.

- **The first time**, the page downloads the model from Hugging Face, about 1.95 GB, then checks and prepares it
  the same way `gliner-runner models install` does. That takes a few minutes. The prepared model (1.75 GB) stays
  in this browser for this site, so later visits start right away. **Remove the downloaded model** deletes it.
- **Speed.** The page uses your graphics card through WebGPU when the browser has it (Chrome, Edge, Safari 26,
  Firefox on Windows and macOS) and your processor otherwise. Before it trusts the graphics card it checks one
  known answer against the reference results. A classification takes well under a second either way.
- **What you need.** A current desktop browser with about 4 GB of free disk space. Private and incognito
  windows usually do not allow websites to store this much, so use a normal window. Phones and tablets are not
  supported.

## Use my machine

**Use my machine** connects the page to the runner on your computer instead. It is faster, can use all three
models, and keeps the model outside the browser.

Run one command in a terminal. It installs gliner-runner if it is missing (or uses the one you have), downloads
the model if needed, allows this page, and starts the runner:

```sh
curl -fsSL https://github.com/stuffbucket/gliner-runner/releases/latest/download/install.sh | sh -s -- --playground --yes
```

With Homebrew, or when gliner-runner is already installed:

```sh
gliner-runner playground --yes
```

The command opens this page already connected. If the page is open, it connects by itself as soon as the runner
is up. The runner keeps running until you press Ctrl+C in the terminal. Chrome may ask whether this site can
reach devices on your local network; allow it, because that is how the page reaches the runner on your computer.

`gliner-runner playground` only adds this page to the runner's list of allowed addresses; see
`gliner-runner cors list`. To remove it: `gliner-runner cors delete <number>`.

## How it works

Both modes use the same program and the same requests. In this tab, the page starts gliner-runner in a
[Web Worker](https://developer.mozilla.org/en-US/docs/Web/API/Web_Workers_API): its model download, checks,
preparation, tokenizer and classification code are the ones the installed runner uses, with the browser's
private storage instead of a disk and [ONNX Runtime Web](https://onnxruntime.ai/docs/tutorials/web/) instead of
the native ONNX Runtime. The page sends it the same `/v1/infer` requests that the
[React app](/gliner-runner/use-in-react/) sends to the runner on your computer.
